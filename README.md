# 移动端效果预览（Mobile Preview）

一个开箱即用的移动端效果预览工具：给出设计稿尺寸，即可查看它在各主流手机上的真机显示效果（显示尺寸、占屏比例、安全区）；也可以把已有的 HTML 页面放进手机壳预览。面向产品经理与运营同学，无需设计背景，也能把准确规格直接转达给设计师。

## 在线使用

打开 GitHub Pages 地址即可使用，无需安装：

**https://aguij.github.io/doubao-mobile-preview/**

## 功能

- **82 款机型库**：iPhone 全系（SE / 5 / 6 / 7 / 8 / X / 11–17）+ 安卓主流机型（三星、小米 / 红米、华为、Google Pixel、摩托罗拉、OPPO、vivo、realme、一加）
- **中英文搜索**：支持中文品牌（小米 / 华为 / 三星…）、英文品牌、型号、屏幕尺寸关键词
- **尺寸校验**：设计稿尺寸 → 真机显示尺寸、占屏高度百分比、内容安全区
- **嵌入已有 HTML**：把现有页面放进手机壳内全屏预览
- **设计稿规格区**：画布、比例、内容安全区、高清导出（2x），可直接转达给设计师

## 两种使用模式

模板通过文件顶部 `CONFIG` 区域的 `contentMode` 切换模式（`index.html` 用编辑器打开即可修改）。

### 模式一：尺寸校验（contentMode: "spec"，默认）

给设计稿尺寸，查看它在各机型真机上的显示效果：

```js
contentMode: "spec",
design: { w: 750, h: 250 },   // 设计稿尺寸（px）
safeArea: { lr: 30, tb: 20 }, // 内容安全区（px）
```

浏览器打开后：手机壳内按设计稿比例显示占位块与安全区虚线，下方标注**真机显示尺寸与占屏比例**，规格区给出画布 / 比例 / 安全区 / 高清导出（2x）——这些参数可以直接转达给设计师。

### 模式二：嵌入已有 HTML（contentMode: "iframe"）

把已有的 HTML 页面放进手机壳里预览：

```js
contentMode: "iframe",
iframeSrc: "assets/user-page.html", // 与模板同目录的相对路径，或完整 URL
```

将你的 HTML 文件放到模板同目录（如 `assets/`），填好 `iframeSrc` 即可在手机壳内全屏预览，配合机型搜索 / 切换查看不同屏幕尺寸下的效果。

## 维护者更新线上版本

```bash
# 更新模板后同步到本仓库
cp <新模板路径> index.html
git add . && git commit -m "update" && git push
```
