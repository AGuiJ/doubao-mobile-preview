# 移动端效果预览（Mobile Preview）

一个开箱即用的移动端效果预览工具：给出设计稿尺寸，即可查看它在各主流手机上的真机显示效果（显示尺寸、占屏比例、安全区）。面向产品经理与运营同学，无需设计背景，也能把准确规格直接转达给设计师。

## 在线使用

打开 GitHub Pages 地址即可使用，无需安装：

**https://aguij.github.io/doubao-mobile-preview/**

## 功能

- **82 款机型库**：iPhone 全系（SE / 5 / 6 / 7 / 8 / X / 11–17）+ 安卓主流机型（三星、小米 / 红米、华为、Google Pixel、摩托罗拉、OPPO、vivo、realme、一加）
- **中英文搜索**：支持中文品牌（小米 / 华为 / 三星…）、英文品牌、型号、屏幕尺寸关键词
- **自动换算**：设计稿尺寸 → 真机显示尺寸与占屏高度百分比
- **设计稿规格区**：画布、比例、内容安全区、高清导出（2x），可直接转达给设计师
- **嵌入预览**（开发用途）：支持将已有 HTML 页面嵌入手机壳内查看

## 如何修改设计稿尺寸

1. 下载 `index.html`，用任意编辑器打开
2. 找到文件顶部 `CONFIG` 区域：

```js
design: { w: 750, h: 250 },   // 改成你的设计稿尺寸
safeArea: { lr: 30, tb: 20 }, // 内容安全区（px）
```

3. 浏览器打开 `index.html` 即可预览

## 维护者更新线上版本

```bash
# 更新模板后同步到本仓库
cp <新模板路径> index.html
git add . && git commit -m "update" && git push
```
